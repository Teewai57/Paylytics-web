# Paylytics — Landing Page & Admin Dashboard

A demo frontend project built to practice and showcase Figma-to-code implementation, responsive layout design, and component architecture using Next.js, React, and TypeScript.

## About

Paylytics is a fictional payment analytics platform for businesses. This project isn't a real product — it's a self-initiated build to demonstrate frontend skills across two common real-world deliverables: a marketing landing page and an admin dashboard.

Most of my recent client work has been under NDA, so this project exists as an open, shareable example of how I approach layout, component structure, and responsiveness from scratch.

## What's included

### Landing Page
- Hero section with headline, subheadline, and CTA
- Feature grid highlighting core product capabilities
- Pricing section with tiered plans
- Testimonials section
- Footer with navigation and social links


## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
